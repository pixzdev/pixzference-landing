Features

More than a pretty face

Pixzference keeps everything OmniRoute is famous for — and adds a layer of its own.

🎨

9 live themes

OmniRoute Lime, Ember, Aurora, Neon, Matrix, Rosewood, Ocean, Candy and Mono Ink — switchable live from Settings → Appearance. Themes are pure CSS token re-points, so every Tailwind utility keeps working. Add your own in ten lines.

📐

3 densities × 3 corners

Compact for small laptops, Cozy by default, Spacious for 4K displays — plus Sharp, Soft and Round corner styles.

⚡

Motion engine

18 named animations: page transitions, staggered reveals, shine sweeps, glass panels, gradient text, aurora backdrops — with a manual off-switch and prefers-reduced-motion respect.

📱

Any viewport

Phones, tablets, laptops, ultrawides. Fluid typography via clamp(), touch targets never below 40px, installable PWA.

☁️

Serverless persistence

Versioned, gzip-compressed snapshot sync to Neon Postgres. Cold starts rehydrate in seconds; tracked writes flush on a debounce.

🔌

Everything OmniRoute

375+ providers, RTK + Caveman compression, auto fallback, MCP/A2A, OpenAI-compatible API, CLI tools — fully compatible, untouched.

Every animation ships twice: once for delight, once for accessibility. The engine honors prefers-reduced-motion at the CSS level (WCAG 2.3.3) and exposes a manual Motion on/off switch in Settings — because vestibular safety should never require OS-level settings.

Security

Hardened by default

The full OmniRoute security surface, plus defaults that refuse to be lazy.

✓

Strong session signing

JWT sessions signed with an auto-generated 64-char secret — never a placeholder, never a tutorial default.

✓

Login rate-limiting

Brute-force lockout with attempt tracking, CSRF protection and secure cookies.

✓

Env-bootstrapped password

Set your dashboard password via INITIAL_PASSWORD, change it in-app, forget "123456" forever.

✓

Scoped API keys

Per-key scopes, request logging and a full audit trail — every credential encrypted at rest.

✓

Fail-safe persistence

If Neon is unreachable, the gateway keeps serving — sync retries quietly on the next write.

✓

Documented hardening

A SECURITY.md written from real-world audits of misconfigured gateway deployments.

Deploy

Running in minutes

Vercel + Neon Postgres for serverless, Docker for everything else.

vercel + neon
# One-click from GitHub
$ git clone https://github.com/pixzdev/pixzference
$ npm install

# Set secrets, then
$ npm run dev
✔ Pixzference ready — http://localhost:3000

# Or ship it to Vercel + Neon
$ vercel --prod
✔ Deployed. DATABASE_URL → Neon, done.

Serverless-ready

A vercel.json ships in the repo. Point DATABASE_URL at Neon and every cold start rehydrates from the latest committed snapshot.

Docker anywhere

A multi-stage Dockerfile with a persistent DATA_DIR for VPS, homelab or cloud machines.

Zero lock-in

MIT licensed, fork-friendly, and glad to merge upstream improvements. Your gateway, your rules.
