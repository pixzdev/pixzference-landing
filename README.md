# Pixzference Landing

Marketing site for [Pixzference](https://github.com/pixzdev/pixzference) — a themeable, motion-rich, security-hardened AI gateway (fork of OmniRoute).

Live at **pixzference.pixz.dev**.

## Stack

Zero-framework: plain HTML + CSS + vanilla JS. No build step.

## Local preview

```bash
npx serve .
# or any static server
```
